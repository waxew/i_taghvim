# آی تقویم (iTaghvim)

## معرفی
برنامه اندرویدی تقویم هوشمند با پشتیبانی از تقویم شمسی، قمری و میلادی و مدیریت مناسبت‌های شخصی.

## وضعیت پروژه
- Version: 1.0.0
- Language: Kotlin
- Package: com.asteam.itaghvim
- Architecture: Clean Architecture + MVVM
- Database: Room
- UI: Jetpack Compose

## امکانات نسخه فعلی
- ساختار اولیه پروژه
- معماری قابل توسعه
- تنظیمات مرکزی برنامه
- آماده‌سازی دیتابیس داخلی
- آماده‌سازی سیستم نسخه و بروزرسانی
